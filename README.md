# Omokage

Omokageは、動画ファイルから特定の人物を検出し、その人物が映っているシーンを抽出して「ダイジェスト動画」や「1分間のドキュメンタリー」を自動生成するアプリケーションです。

## 特徴

- **顔認識による動画解析**: 指定したフォルダ内の全ての動画をスキャンし、特定の人物を自動で追跡します。
- **AI BGM生成**: Stable Audioを利用して、動画の雰囲気に合わせたオリジナルのBGMを自動生成します（Hugging Faceのトークンが必要です）。
- **ドキュメンタリー生成**: 抽出したクリップを繋ぎ合わせ、BGMや字幕、カラーフィルターを適用して高品質なショートムービーを作成します。
- **簡単操作**: 直感的なGUIで、専門知識がなくても動画編集が可能です。

## 必要条件

- Python 3.10以上
- ffmpeg (動画処理に必要)
- GPU (推奨: NVIDIA GPU または Mac Apple Silicon)

## セットアップ

1. リポジトリをクローンまたはダウンロードします。
2. 仮想環境を作成し、依存関係をインストールします：
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # Windowsの場合は .venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. アプリケーションを起動します：
   ```bash
   python app.py
   ```

## 使い方

1. **人物登録**: 「スキャン」タブで、編集したい人物の写真を登録します。
2. **動画スキャン**: 動画が保存されているフォルダを選択してスキャンを開始します。
3. **ダイジェスト作成**: 「編集 / 作成」タブで、登録した人物を選択し、動画の雰囲気や期間を指定して生成を開始します。
4. **音声テキスト抽出**: 「スキャン」タブの「音声テキスト抽出」で、スキャン済み動画の音声を文字起こし（faster-whisper、ローカル実行）し、発話者を判定したテキストを `Documents/Omokage/Output/transcripts/` に保存します。初回は音声認識モデルをダウンロードします。
   - 音声認識モデルは画面で選べます。`large-v3-turbo`（推奨、約1.5GB）、`large-v3`（最高精度・約5倍遅い、約3GB）、`small`（高速・低精度）の3種類です。モデルを変えると、次の抽出で全動画を文字起こしし直します。
   - 幼児の短い発話を落とさないよう、無音検出（VAD）は小さな声・短い発話・短い間にも反応する設定にしています。
   - 雑音から作られた可能性のある発話（単語の確からしさが低い、同じ言葉の繰り返し、「ご視聴ありがとうございました」などの定型文）は消さずに残し、`low_confidence` / `flags` で印を付けます。テキストでは「(低確度)」と表示します。
   - 発話者は**口元の動き**で判定します。発話中に口が動いている登録人物をその発話者とし、映っている全員の口が動いていない発話や誰も映っていない発話は「撮影者」の発話とします。顔が小さい・横向きなどで口元を判定できない場合は、映っている人物の発話と推定し「(推定)」と表示します。
   - 食事中など話していなくても口が動く人のために、発話の合間の口の動きを「ふだんの口の動き」として測り、それを上回ったときだけ話していると判定します。
   - 赤ちゃんは話していなくても口がよく動くため、人物リストの 🗣 ボタンで「話し始めた日付」を設定してください。その日付より前の動画では、その人物を発話者にしません。
   - `会話タイムライン.txt` には、動画ごとに全員（人物・撮影者）の発話を時刻順に並べます。`対話ペア.txt` には、話者が替わった直後の受け答え（例: 撮影者「いける?」→ はる「いける」）を並べます。`transcripts.json` の `conversations` / `dialogue_pairs` にも同じ内容を保存します。
   - `utterances.jsonl` は機械処理用です。撮影者を含む全員の発話を、1行1件の JSON で1ファイルにまとめます。主な項目は `video`, `recorded_at`, `start`, `end`, `text`, `speaker`, `speaker_estimated`, `overlap_with`, `on_screen`, `avg_logprob`, `no_speech_prob`, `word_prob`, `low_confidence`, `flags` です。
5. **設定**: BGMを生成するには、Hugging Faceの「Settings / About」ページでアクセストークンを入力してください。
